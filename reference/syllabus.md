# Claude Code: Zero To Hero
### For Developers, DevOps, Cloud, SRE, and Platform Engineers — Anyone Who Wants to Actually Use Claude Code

**Format:** Self-paced, recorded | **Language:** English | **Channel:** trainwithshubham.ai
**Built from:** Anthropic's official Claude Code documentation and changelog as of September 2026

---

## How This Course Is Structured

15 modules across 4 phases, taken in order by every learner — there is no separate track split. Modules 7–9 build a first project (a portfolio site); Modules 12–14 build and ship a second, larger one (a URL shortener), taking it from a local build through CI/CD and production deployment.

| Phase | Modules | What it covers |
|---|---|---|
| Zero → Comfortable | 1–3 | How Claude works, prompt engineering fundamentals, and what makes an AI system agentic |
| Comfortable → Productive | 4–9 | Getting started, setup/config/memory, built-in tools, planning and building a first project, Skills/commands/sub-agents |
| Productive → Advanced | 10–13 | MCP, hooks and plugins, an advanced URL shortener project, multi-agent prompting strategies |
| Advanced → Hero | 14–15 | CI/CD and reliability, and what comes after the course |

## Notes for Production
- Every module references named, current features (auto mode, plan mode, MCP, Agent Skills, sub-agents, the GitHub Action, Vercel deployment, etc.) pulled from Anthropic's official docs/changelog as of Sep 15, 2026 — not third-party recap blogs, which had inconsistent claims.
- Claude Code ships weekly, so the `last_verified` date in each module's HTML comment is worth keeping current.
- Modules 7–9 (portfolio project) and 12–14 (URL shortener, deployed) are the two hands-on projects that carry the course — there is no separate capstone module or two-track split; Module 15 closes the course by turning the URL shortener into portfolio evidence instead of introducing new project work.
